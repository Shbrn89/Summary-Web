About Project

How This Application Works

Training Checkpoint

The Transformer models are loaded from local trained model folders created during the training process.

TF-IDF Baseline

TF-IDF is used as the extractive baseline to compare against Transformer-based abstractive summarization models.

Document Input

Users can paste text directly or upload PDF and TXT files. The extracted text is cleaned before summarization.

Deployment Interface

The web application acts as an inference interface for the trained summarization models.
